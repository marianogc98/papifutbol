# Contexto Spec-Kit - PapiFutbol

Esta carpeta contiene la configuración y contexto para spec-kit.

## Archivos

- **`context.md`** - Contexto consolidado del proyecto
- **`spec-kit.json`** - Configuración de spec-kit
- **`memory/constitution.md`** - Reglas y principios del proyecto

## Uso

Spec-kit usará estos archivos para:
- Entender el contexto del proyecto
- Generar código según las especificaciones
- Mantener consistencia con las reglas establecidas

## Referencias

Los archivos principales de especificación están en:
- `files/specify.md` - Especificación completa
- `files/database-setup.md` - Setup de BD

## Actualización

Cuando cambies algo en el proyecto, actualiza:
1. `context.md` - Si cambian características principales
2. `spec-kit.json` - Si cambia la estructura o stack
3. `memory/constitution.md` - Si cambian reglas de desarrollo
